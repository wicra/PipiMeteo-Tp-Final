Contexte

Objectif du projet

Réaliser en groupe une application météo avec Angular et l'API OpenWeather, en mettant en pratique les fondamentaux du cours.

  • Composants Angular, formulaires réactifs, routing, services
  • Communication entre composants et gestion d'état (signals)
  • Requêtes HTTP, API REST, données JSON
  • Gestion des erreurs et des états de chargement

Gestion d'état

Signals + RxJS

  • Statuts explicites : idle / loading / success / error (computed signals)
  • debounceTime + distinctUntilChanged pour limiter les appels API
  • switchMap pour annuler une recherche obsolète
  • catchError transforme l'erreur en message utilisateur, finalize nettoie le chargement
  • takeUntilDestroyed pour désabonner proprement
API & Postman

OpenWeather

  • GET /weather et GET /forecast, paramètres q + appid
  • Conversion Kelvin → Celsius et m/s → km/h dans WeatherService
  • Erreurs gérées : 404 ville introuvable, 429 trop de requêtes, erreur générique
  • Collection Postman documentée (Current Weather, Forecast)
